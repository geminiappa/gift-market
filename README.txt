GIFT MARKET — обновлённый проект

ЗАПУСК
1. Распакуйте архив.
2. Откройте папку gift_market в VS Code.
3. Запустите index.html через расширение Live Server.

АНИМАЦИИ
В каталоге используются анимированные WebP с прозрачностью, 60 кадров/с и длительностью исходного ролика 3 секунды: исходные цветные
фоны и подписи удалены, объекты вписаны в квадратный кадр без обрезания.
Оригинальные MP4 сохранены в assets/source/.

ФУНКЦИИ
- Отдельные вкладки: Главная, Каталог, О магазине, Оплата, FAQ, Контакты.
- Отдельная страница каждого подарка.
- Цены TON / BYN / STARS в карточках и карточках товара.
- Корзина с количеством, выбором валюты и сохранением в localStorage.
- Water Tank отмечен как БРОНЬ и недоступен для добавления в корзину.
- Адаптивный интерфейс для компьютера и телефона.

ВАЖНО
Оплата пока демонстрационная. Заявки, корзина и сообщения сохраняются только в
localStorage текущего браузера. Для реальных платежей и заказов нужен backend,
проверка транзакций и подключение платёжных провайдеров.
